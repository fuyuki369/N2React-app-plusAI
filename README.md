※ 本アプリはローカル環境で起動する必要があります。

※ ターミナル（黒い画面）を使用します。

※ Node.js がインストールされている必要があります。


## 動作確認方法（履修登録システム）

### 1. バックエンド（画面の裏側の処理）を起動します

1. ダウンロードしたフォルダを開き、ターミナルを起動します。
2. 以下のコマンドを上から順に入力してください。
   
cd BackEnd

cd project

node index.mjs

3. エラーが表示されず、サーバーが起動すれば成功です。

---

### 2. フロントエンド（画面）を起動します

1. 別のターミナルを開き、以下のコマンドを入力してください。

cd FrontEnd

cd my-app

npm run dev

2. ターミナルに表示される  
   http://localhost:xxxx 
   をブラウザで開いてください。

---

### 3. 操作方法

1. 画面の案内に沿って料理の条件を入力します。
2. 「この条件をAIに伝える」ボタンをクリックします。
3. 条件に沿ったレシピが表示されます。
